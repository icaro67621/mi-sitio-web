Seguridad en APIs

VulnBank API: una API bancaria real (ficticia) para practicar el OWASP API Security Top 10. Se publica en dos versiones: vulnerable (para atacar) y endurecida (con los fallos corregidos).

API activa: comprobando…

Abrir la consola Ver /api/lab
AVISO

Entorno de entrenamiento

La versión vulnerable contiene fallos intencionales. Todos los datos, contraseñas y "secretos" son ficticios, viven solo en memoria y se pueden restaurar en cualquier momento. El SSRF está simulado: la API no hace peticiones reales a ningún sitio. Ataca solo esta API (/api/lab/…), nunca el resto del sitio ni otros sistemas.

Dos versiones

Mismos endpoints, mismos usuarios, comportamiento distinto.

VULNERABLE

Para atacar

12 vulnerabilidades: BOLA, JWT sin firma, enumeración, exposición de datos, asignación masiva, BFLA, lógica de negocio, SSRF, mala configuración, API antigua, inyección NoSQL y consumo sin límite.

ENDURECIDA

Corregida

Autorización por objeto y por función, JWT estricto con caducidad, límite de intentos, DTOs, listas blancas, validación de tipos, errores genéricos y paginación limitada.
